# Proyecto-Estructura-
Aquí vamos a ir subiendo los avances del proyecto de la clase de estructura de Datos
Para que esta parte del codigo inicial funcione es necesario tener las siguientes bibliotecas instaladas en tu computador:
---
```powershell
  pip install pandas
  pip install matplotlib
  pip install openpyxl
```
o en caso de que quieras descargar todos al tiempo:

```powershell
pip install pandas matplotlib openpyxl
```
---
para instalar las simplemente copia esas lineas en tu consola
adicionalmente es necesario que vincules una hoja de excel que funciona como la base de datos del codigo, por esto es importante que cambies
la variable "archivo_excel" con la ruta donde se encuentra tu base de datos para que el codigo funcione correctamente.
